# CloudNest User Guide

## 1.1 Creating an Account
You can sign up at cloudnest.example/signup using an email address or a Google account.
After signing up, a verification email is sent and the link inside it is valid for 24 hours.
Every new account starts on the Free plan with 5 GB of storage.

## 1.2 Uploading Files
Files can be uploaded by dragging them into the browser window or by clicking the Upload button.
The maximum size for a single file is 2 GB on the Free plan and 50 GB on paid plans.
The desktop app syncs a folder on your computer automatically every few seconds.
Uploads that are interrupted resume automatically when your connection comes back.

## 1.3 Sharing Files and Folders
To share, right-click a file or folder and choose Share, then enter an email or create a link.
Shared links can be set to View only or Can edit.
Paid plans can add a password and an expiry date to shared links.
You can stop sharing at any time from the Shared tab, which disables the link immediately.

## 1.4 Two-Factor Authentication
Two-factor authentication (2FA) adds a six-digit code from an authenticator app at login.
Turn it on from Settings, then Security, then Enable 2FA, and scan the QR code.
Save the ten backup codes shown during setup, because each one can be used once if you lose your phone.

## 1.5 Deleting and Recovering Files
Deleted files move to the Trash instead of being removed right away.
Files stay in the Trash for 30 days on the Free plan and 180 days on paid plans.
To recover a file, open Trash, select it and click Restore.
Emptying the Trash deletes files permanently and they cannot be recovered by support.
